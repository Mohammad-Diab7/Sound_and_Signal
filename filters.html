What a filter does

A filter is a circuit that keeps some frequencies and turns others down. Every sound is a mix of frequencies, so a filter changes the mix, and the mix is what you hear as tone.

You already use filters. The bass and treble knobs on a stereo are filters: one raises or lowers the low frequencies, the other the high ones. A wall does it too. Low rumbles pass through it but high frequencies are absorbed, so music next door sounds muffled.

Try it in the Filter Lab above. A square wave is a stack of harmonics. A low-pass filter removes the high ones, and the buzzy sound turns dull.

Passband
The frequencies that get through almost unchanged.
Stopband
The frequencies that are turned down a lot.
Cutoff
Where the filter starts to take effect. At the cutoff the level is down 3 dB, about 70% of the original.
Attenuation
How much a frequency is turned down, usually measured in decibels (dB).
Deep dive: the transfer function

A linear filter multiplies each sine wave by a complex number that depends on its frequency. That number is the transfer function, the ratio of output to input.

H(f) = Y(f) / X(f)
|H(f)| = gain            gain in dB = 20·log10|H(f)|
∠H(f)  = phase shift

The magnitude |H| scales the sine wave and the phase ∠H shifts it in time. For a periodic input with sine coefficients b_n at n·f0, the output is:

y(t) = Σ b_n · |H(n·f0)| · sin(2π·n·f0·t + ∠H(n·f0))

This is exactly how the Filter Lab draws its output waveform and its output harmonics. Each harmonic is scaled by the filter's gain at that frequency, then the scaled sine waves are added back together.

Low-pass, high-pass, band-pass

A low-pass filter passes low frequencies and cuts high ones. A high-pass does the opposite. A band-pass keeps a band in the middle and cuts both sides.

The simplest filter is an RC circuit: one resistor and one capacitor. A capacitor lets fast changes through more easily than slow ones. Put it across the output and high frequencies leak away, which gives a low-pass. Swap the two parts and the lows are blocked instead, which gives a high-pass. Join a high-pass and a low-pass and you get a band-pass.

The cutoff is set by fc = 1/(2π·R·C). A bigger resistor or capacitor lowers the cutoff. Type values into the RC calculator in the lab and press SET CUTOFF to try them.

Deep dive: RC filter math

Low-pass RC

H(jω) = 1 / (1 + jωRC)
|H(f)| = 1 / √(1 + (f/fc)²)
fc = 1 / (2πRC)
phase = −arctan(f/fc)

High-pass RC

H(jω) = jωRC / (1 + jωRC)
|H(f)| = (f/fc) / √(1 + (f/fc)²)
phase = 90° − arctan(f/fc)

At f = fc the gain is 1/√2 ≈ 0.707, which is −3 dB, and the phase is −45° for the low-pass and +45° for the high-pass. Far below fc a low-pass has gain 1; far above it the gain falls by 20 dB for every factor of 10 in frequency.

Example: R = 10 kΩ and C = 10 nF give fc = 1/(2π · 10 000 · 10⁻⁸) ≈ 1.59 kHz.

Order, slope and equalizers

One RC stage cuts gently. To cut harder, stack stages. The number of stages is the filter's order, and a higher order gives a steeper slope, so unwanted frequencies are removed more sharply. Switch ORDER between 2, 4 and 8 in the lab and watch the slope of the Bode plot change.

An equalizer (EQ) is a set of band filters, each controlling one slice of the spectrum, with its own gain control. A graphic EQ has a row of sliders at fixed frequencies. A parametric EQ also lets you move the center frequency and set the width of each band.

Deep dive: roll-off and Bode plots

Each order adds −20 dB per decade of roll-off, which is about −6 dB per octave.

slope ≈ −20·N dB/decade = −6·N dB/octave     (N = order)
  • N = 1 (one RC stage): −20 dB/decade, −6 dB/octave.
  • N = 2: −40 dB/decade, −12 dB/octave.
  • N = 4: −80 dB/decade, −24 dB/octave.
  • N = 8: −160 dB/decade, −48 dB/octave.

Reading a Bode plot. The frequency axis is logarithmic, so a fixed number of dB per decade is a straight line. The flat part at 0 dB is the passband. The point where the curve is down 3 dB is the cutoff fc. Beyond it the curve falls along the straight slope. For a band-pass, the peak is at the center frequency and Q = fc / (f_high − f_low), measured between the two −3 dB points, so a higher Q means a narrower band.

The lab builds each order from cascaded second-order Butterworth stages (2nd order = 1 stage, 4th = 2, 8th = 4). Butterworth stages give the flattest passband and put every order exactly at −3 dB at fc. For a band-pass, ORDER counts two per stage, and each extra stage gives steeper skirts and a narrower band.
